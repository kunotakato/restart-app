## T19・T20 の確認方法

- **ブラウザ**：ページ読み込み時に `Date` をテスト用の時計に置き換え、時刻のずれだけを操作しました。パソコンのシステム時刻は変更していません
  - 23:59:57 に設定して待つと、0時の約27秒後に表示が翌日に変わりました（30秒ごとの定期チェック。要件は60秒以内）
  - `visibilitychange` を発生させると、1秒以内に翌々日に変わりました（画面復帰）
  - 日付だけ進めてすぐ「達成」を押すと、保存されず「日付が変わりました」と表示され、日付も最新に変わりました（T20）
- **自動テスト**：Vitest のテスト用の時計（`vi.useFakeTimers` / `vi.setSystemTime`）で、定期チェックが60秒以内であること、`focus`・`visibilitychange` で再取得されること、解除後に止まることを確認しました
